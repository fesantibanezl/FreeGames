# FreeGames

Catálogo web de videojuegos creado con HTML5 y CSS3 para la actividad de Programación Web.

## Cómo abrir el sitio

Abre `index.html` en un navegador. No requiere instalación ni servidor.

## Estructura

- `index.html`: página principal y listado de categorías.
- Cinco páginas internas, una por categoría.
- `css/style.css`: estilos compartidos.
- `img/`: ilustraciones originales utilizadas por el sitio.
